# Сайт-приглашение · Сергей и Ксения · 12.12.2026

Одностраничный сайт с анкетой гостя. Ответы падают в вашу Google-таблицу,
смотреть их удобно на отдельной странице `admin.html`.

Хостинг — бесплатный (GitHub Pages), приём ответов — бесплатный (Google Apps
Script), ограничений по количеству гостей нет.

Вёрстка проверена на ширинах от 280 до 1920 пикселей — горизонтальной прокрутки
нет нигде, так что сайт нормально открывается и на старых узких телефонах, и на
большом мониторе.

---

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | сам сайт-приглашение (ваш дизайн из Claude Design + отправка анкет) |
| `support.js` | движок дизайна, без него сайт не откроется |
| `config.js` | **единственный файл, который надо отредактировать** — сюда вписывается ссылка на скрипт |
| `rsvp-backend.js` | отправка анкет в таблицу |
| `admin.html` | страница со сводкой: кто придёт и что будет есть |
| `apps-script/Code.gs` | код, который вставляется в Google-таблицу |
| `Сергей и Ксения свадьба/` | исходники дизайна из Claude Design (для сайта не нужны, но пусть лежат) |

## Шаг 1. Google-таблица и скрипт

1. Откройте <https://sheets.new> — создастся пустая таблица.
   Назовите её, например, **«Гости 12.12.2026»**.
2. В меню: **Расширения → Apps Script**.
3. Удалите весь текст в открывшемся редакторе и вставьте туда содержимое
   файла `apps-script/Code.gs`.
4. В самом верху вставленного кода найдите строку:

   ```js
   var ADMIN_TOKEN = 'ПОМЕНЯЙТЕ_В_РЕДАКТОРЕ_APPS_SCRIPT';
   ```

   Замените на свой пароль (латиница и цифры, без пробелов). Он понадобится,
   чтобы открывать `admin.html`.

   > **Меняйте его только здесь — в редакторе Apps Script.** В файл
   > `apps-script/Code.gs` в GitHub-репозитории настоящий пароль вписывать
   > нельзя: репозиторий публичный, и тогда список гостей сможет выгрузить
   > кто угодно. Пусть там остаётся заглушка.
5. Сохраните: **Ctrl + S**.
6. Вверху выберите функцию **`testAddRow`** и нажмите **Выполнить**.
   Google попросит разрешения — это нормально:
   *Проверить разрешения → выберите свой аккаунт → Дополнительные настройки →
   Перейти к проекту «Без названия» (небезопасно) → Разрешить.*

   После этого в таблице появится лист **«Ответы»** с одной тестовой строкой —
   её потом можно удалить вручную.

## Шаг 2. Публикация скрипта

1. В редакторе скрипта справа вверху: **Развернуть → Новое развёртывание**.
2. Нажмите на шестерёнку рядом с «Выберите тип» и выберите **Веб-приложение**.
3. Заполните:
   * **Описание** — любое, например «Анкеты гостей»
   * **Запуск от имени** — **Я** (ваш адрес)
   * **У кого есть доступ** — **Все**  ← обязательно, иначе гости не смогут отправить анкету
4. **Развернуть** → скопируйте **URL веб-приложения**.
   Он заканчивается на `/exec`, например:

   ```
   https://script.google.com/macros/s/AKfycbx...../exec
   ```

## Шаг 3. Вписать ссылку в сайт

Откройте `config.js` в блокноте и вставьте скопированную ссылку:

```js
window.WEDDING_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/AKfycbx...../exec'
};
```

Сохраните файл.

## Шаг 4. Выложить сайт на GitHub Pages

1. Зайдите на <https://github.com> под своим аккаунтом.
2. **New repository** → имя, например `svadba` → **Public** → **Create**.
   *(Для бесплатных Pages репозиторий должен быть публичным. Сам сайт при этом
   выглядит как обычный сайт — код видно только тем, кто зайдёт на GitHub.)*
3. На странице репозитория: **Add file → Upload files** и перетащите в окно
   **файлы** (не папку целиком):

   ```
   index.html
   admin.html
   config.js
   rsvp-backend.js
   support.js
   .nojekyll
   ```

   Нажмите **Commit changes**.
4. **Settings → Pages**:
   * **Source** — *Deploy from a branch*
   * **Branch** — `main`, папка `/ (root)`
   * **Save**
5. Через 1–2 минуты сайт откроется по адресу:

   ```
   https://ВАШ-ЛОГИН.github.io/svadba/
   ```

   Эту ссылку и рассылайте гостям.

## Как смотреть ответы

**Вариант 1 — таблица.** Просто откройте свою Google-таблицу, лист «Ответы».
Одна строка = один гость.

**Вариант 2 — красивая сводка.** Откройте

```
https://ВАШ-ЛОГИН.github.io/svadba/admin.html
```

и введите пароль из `ADMIN_TOKEN`. Там будет:

* сколько человек ответило и сколько придёт;
* сколько порций каждого горячего и каждого салата;
* поимённый список;
* **готовый текст заявки для ресторана** — кнопка «Скопировать текст»;
* выгрузка в CSV (открывается в Excel) и кнопка «Печать».

Если гость заполнил анкету дважды — учитывается последний ответ, предыдущий
прячется. Показать их можно кнопкой «Показать перезаписанные».

> Ссылку на `admin.html` гостям не давайте. Пароля на сайте нигде нет, но
> страница открыта по прямому адресу — защищает именно пароль.

## Что можно поменять

Всё в `index.html`, обычным поиском по тексту:

| Что | Как найти |
|---|---|
| Дата в обратном отсчёте | `2026-12-12T12:20:00+03:00` |
| Срок ответа | `Пожалуйста, ответьте до 20 ноября 2026` |
| Адрес ЗАГСа | `ул. Тихвинская, 16/11` |
| Ресторан и его адрес | `ул. Мусы Джалиля-Духовская, 23А` |
| Текст про цветы | `Небольшая просьба` |
| Блюда | массивы `MAINS` и `SALADS` внизу файла |

**Важно:** если меняете блюда — поменяйте их **и** в `apps-script/Code.gs`
(массивы `MAINS` и `SALADS` вверху файла), иначе выбор гостя не запишется в
таблицу. После правки `Code.gs` обязательно переразверните скрипт:
**Развернуть → Управление развёртываниями → карандаш → Версия: Новая версия →
Развернуть**. Ссылка `/exec` при этом не меняется.

### Дресс-код

В дизайне есть готовый блок про пастельный дресс-код, он сейчас выключен.
Чтобы включить, найдите в `index.html` строку

```
&quot;showDressCode&quot;:{&quot;editor&quot;:&quot;boolean&quot;,&quot;default&quot;:false
```

и замените `false` на `true`.

### Как устроена анкета

1. **«Сможете быть с нами?»** — «Да, будем на свадьбе» / «К сожалению, не смогу
   прийти». При выборе «не смогу» выбор блюд скрывается, остаётся только имя и
   комментарий. В таблице такой гость записывается со значением «нет» в колонке
   «Придёт», а в сводке попадает в счётчик «Не смогут» и не учитывается при
   подсчёте порций.
2. **Гость** — имя и фамилия, горячее, салат. Кнопкой «Добавить гостя» можно
   заполнить одну анкету на пару или на семью — каждый получит свою строку в
   таблице.
3. **Комментарий** — необязательный, один на анкету (аллергия, пожелания по
   музыке). Попадает в колонку «Комментарий» и отдельным блоком «Пожелания и
   особенности» в текст заявки для ресторана.

## Если вы переделали дизайн в Claude Design

При новой выгрузке из Claude Design ваш `index.html` перезапишется, и вместе с
ним пропадут кнопка «не смогу прийти», поле комментария и отправка в таблицу.

**Самое простое:** сохраните текущий `index.html` в отдельную папку перед
выгрузкой и потом перенесите правки — или пришлите новую выгрузку мне, перенос
занимает пару минут.

Если делать руками, вот все места (все — в `index.html`, больше ничего трогать
не нужно):

1. В `<head>`, после `<script src="./support.js"></script>`:

   ```html
   <script src="./config.js"></script>
   <script src="./rsvp-backend.js"></script>
   ```

2. В разметке анкеты — блок `<sc-for list="{{ attendOpts }}">` с двумя кнопками
   выбора, `<sc-if value="{{ g.coming }}">` вокруг блоков «Горячее блюдо» и
   «Салат», и `<textarea ... onChange="{{ onComment }}">` для комментария.

3. В экране благодарности — `{{ thanksText }}` вместо жёстко вписанного текста
   и `<sc-if value="{{ g.coming }}">` вокруг строки с блюдами.

4. В `<script type="text/x-dc">` внизу файла:
   * в `state = { ... }` добавить `coming: true, comment: '', sending: false`;
   * метод `attendVals()`;
   * в `guestVals()` — поле `coming: this.state.coming`;
   * в `renderVals()` — `attendOpts`, `comment`, `onComment`, `thanksText`,
     `sendLabel`, поле `coming` в `summary`;
   * в `submit` — проверять блюда только при `s.coming` и вызывать
     `window.WeddingRSVP.submit(this, s.guests, { attending: s.coming, comment: s.comment })`.

Файлы `config.js`, `rsvp-backend.js`, `admin.html` и `Code.gs` при этом не
меняются.

## Другие бесплатные хостинги

* **Netlify Drop** — <https://app.netlify.com/drop>: просто перетащите папку в
  окно браузера, сайт поднимется за 10 секунд. Аккаунт нужен, только если
  хотите закрепить адрес.
* **Cloudflare Pages** — тоже бесплатно, подключается к тому же
  GitHub-репозиторию.

Свой красивый адрес (например `sergey-i-ksenia.ru`) можно прикрутить к любому
из них: домен покупается отдельно (~200–900 ₽/год), хостинг остаётся бесплатным.

## Если что-то не работает

**Анкета не отправляется, пишет «нет связи».**
Проверьте, что в `config.js` ссылка заканчивается на `/exec`, и что при
развёртывании выбрано «У кого есть доступ: **Все**».

**`admin.html` пишет «неверный пароль».**
Пароль должен совпадать с `ADMIN_TOKEN` в `Code.gs` буква в букву. Если вы
меняли `Code.gs` — не забудьте переразвернуть скрипт (см. выше).

**Сайт открывается, но пустой.**
Скорее всего, рядом с `index.html` не лежит `support.js` — загрузите его.

## Правка ответов из сводки

На странице `admin.html` у каждого гостя есть кнопка **«Изменить»**: поменять имя,
статус «придёт / не сможет», горячее, салат и комментарий. Блюда выбираются из
выпадающего списка, так что опечаток не будет.

Там же кнопка **«Убрать гостя»**. Она **не стирает строку** — только помечает её
в колонке «Статус» словом `убран`. Такой гость пропадает из счётчиков, графиков
и заявки для ресторана, но остаётся в таблице. Вернуть его можно кнопкой
**«Показать скрытых» → «Вернуть»**.

Сделано так намеренно: настоящее удаление через интернет означало бы, что любой,
кто узнает пароль, сможет одним запросом снести все ответы гостей. Пометка —
обратима, а физически удалить строку всегда можно руками в самой таблице.

Правка защищена: перед записью скрипт сверяет имя в строке с тем, которое было
на экране. Если таблицу успели поменять в другом окне — вместо порчи чужой
записи вы увидите «таблица изменилась, обновите страницу».
